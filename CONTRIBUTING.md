# Contributing

Thanks for helping improve the SealedCash SDK. Open an issue before substantial
changes, then submit a focused pull request against the default branch.

Run `npm ci`, `npm run typecheck`, and `npm test` before submitting. Keep public
types aligned with the API contract, avoid adding dependencies without a clear
need, and never commit credentials or production deployment values.

Questions: [support@sealedcash.com](mailto:support@sealedcash.com).
